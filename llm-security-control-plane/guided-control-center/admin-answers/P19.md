# P19 보강 UI+Starter 최종 재감사

## 판정

**채점 가능한 완성 답을 정확히 작성할 수 있다.**

보강된 UI는 이전에 불명확할 수 있었던 root Span과 identity 검증의 경계를 명확히 한다. 서버 수집기가 `client_ip`, `user_id`, `policy_rule`과 root Span을 먼저 대조하고, 학습자 함수에는 root를 제외한 정규화 bundle만 전달한다. 또한 대상 외 불완전 행의 제외 방식, trace ID 타입, 반복 stage 이름 허용, sequence 검증, block의 stop stage 조건이 모두 제공된다.

## 완성된 `investigation.py`

```python
"""P19: 제공된 행 선택·순서 검사 흐름에 사건 판정식을 채우세요."""


def analyze_incident(bundle, request_id):
    """요청 한 건의 증거만 연결하고 누락·모순은 ValueError로 거부합니다."""
    if not isinstance(bundle, dict) or any(not isinstance(bundle.get(kind), list) for kind in ("logs", "spans", "closures", "downstream_calls")):
        raise ValueError("evidence collections must be lists")
    # 제공 흐름: 다른 요청의 행은 필드가 비어 있어도 검사하지 않습니다.
    selected = {}
    for kind in ("logs", "spans", "closures", "downstream_calls"):
        selected[kind] = [row for row in bundle.get(kind, [])
                          if isinstance(row, dict) and row.get("request_id") == request_id]

    logs, spans = selected["logs"], selected["spans"]
    closures, calls = selected["closures"], selected["downstream_calls"]
    if len(logs) != 1 or len(closures) != 1:
        raise ValueError("decision log or closure missing")
    log, closure = logs[0], closures[0]
    if not log.get("trace_id") or log.get("trace_id") != closure.get("trace_id"):
        raise ValueError("trace mismatch")

    ordered = sorted(spans, key=lambda row: row.get("sequence", -1)
                     if type(row.get("sequence")) is int else -1)
    stages = []
    for expected, span in enumerate(ordered, start=1):
        if type(span.get("sequence")) is not int or span["sequence"] != expected:
            raise ValueError("stage sequence mismatch")
        if span.get("trace_id") != log["trace_id"]:
            raise ValueError("stage trace mismatch")
        stage = span.get("stage")
        if not isinstance(stage, str) or not stage:
            raise ValueError("stage missing")
        stages.append(stage)

    trace_id = log["trace_id"]
    if not isinstance(trace_id, str) or not trace_id or any(row.get("trace_id") != trace_id for row in spans + calls):
        raise ValueError("trace mismatch")
    decision = log.get("decision")
    if decision not in ("allow", "block") or "stop_stage" not in log:
        raise ValueError("decision missing")
    stop_stage = log["stop_stage"]
    if not stages or (decision == "allow" and stop_stage is not None) or (decision == "block" and stop_stage != stages[-1]):
        raise ValueError("stop stage mismatch")
    if closure.get("closed") is not True:
        raise ValueError("request not closed")
    downstream_count = closure.get("downstream_count")
    if type(downstream_count) is not int or downstream_count < 0 or downstream_count != len(calls):
        raise ValueError("downstream count mismatch")
    return {"request_id": request_id, "trace_id": trace_id, "decision": decision, "stages": stages, "stop_stage": stop_stage, "downstream_count": downstream_count}
```

## 구현이 충족하는 조건

- 네 collection을 request ID로 먼저 거르므로 대상 외 불완전 행의 다른 필드를 보지 않는다.
- 대상 Log와 closure가 각각 정확히 한 건인지 확인한다.
- 대상 단계 Span 누락을 거부한다.
- Log에서 얻은 trace ID가 비어 있지 않은 문자열인지 확인한다.
- 대상 Log·Span·closure·downstream call의 trace ID가 모두 같은지 확인한다.
- decision을 `allow` 또는 `block`으로 제한한다.
- stage를 비어 있지 않은 문자열로, sequence를 bool이 아닌 정수로 확인한다.
- 정렬된 sequence가 정확히 `1..N`인지 비교하므로 누락과 중복을 함께 거부한다.
- stage 이름의 반복은 별도 오류로 취급하지 않는다.
- allow에는 null stop stage를 요구한다.
- block에는 sequence상 마지막 stage와 정확히 같은 stop stage를 요구한다.
- closure가 실제로 닫혔는지 확인한다.
- 기록된 downstream count가 음이 아닌 정수이며 실제 대상 호출 행 수와 같은지 확인한다.
- 차단 전 실제 호출이 있으면 그 수를 그대로 반환한다.
- 요구된 여섯 필드만 반환한다.

## 남은 누락 여부

**완성 구현을 막는 조건은 남아 있지 않다.**

입력은 각 collection의 행이 사전이라고 명시하므로, 대상 필터에서 `row.get()`을 사용할 수 있다. root Span과 identity metadata는 서버 수집기가 학습자 함수 호출 전에 검증한다고 명시됐으므로 함수에서 다시 처리하지 않는 것이 계약에 맞다.

실제 기본·역순·손상 사본 12개를 실행한 결과는 이 제한 입력만으로 확인할 수 없다. 이는 코드 계약의 누락이 아니라 빌드 후 수행할 실행 검증이다.
